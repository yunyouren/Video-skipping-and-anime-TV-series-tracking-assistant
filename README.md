# 视频跳略与追番追剧助手

[![Version](https://img.shields.io/badge/version-4.7-00aeec)](manifest.json)
![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue)

适用于 Chrome / Edge 的视频辅助扩展：设置片头片尾跳过、记录每集播放进度、管理追番收藏，并在下次打开时续看。数据保存在当前浏览器本地，不需要扩展账号。

## v4.7 更新

- **快捷设置**：片头、片尾输入框旁的“取当前”按钮，直接使用当前播放位置。
- **排序与置顶**：支持最近观看、名称排序；常看的收藏可置顶。
- **插件内选集**：展开集数，查看未看、看到一半、已看完状态，点击续看。
- **每集独立进度**：回看旧集时保留各集自己的播放位置。
- **故障诊断**：底部“反馈诊断”复制版本、站点域名、识别结果和保存状态。
- **紧凑布局**：排序与备份共用工具栏，选集使用双列按钮，诊断文本默认收起。

### 本地加载：固定文件夹，修改后重新加载

1. 下载源码并解压到一个固定文件夹，或克隆本仓库。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载解压缩的扩展”，选择**直接包含 `manifest.json` 的仓库根目录**。
4. 以后在同一目录更新代码，点击该扩展的“重新加载”，再刷新视频网页。

已经使用本仓库根目录加载的用户，不需要重复解压 ZIP 或创建版本文件夹。保持目录路径不变，不要卸载后重装。

如果从商店版本或其他目录切换，先在旧扩展中导出收藏备份，再在新扩展导入并核对设置。不同安装来源可能对应不同扩展身份，数据不会自动搬迁。详见[本地加载说明](本地加载说明.md)。

## 快速开始

1. 打开视频并开始播放，点击扩展图标。
2. 点击“+ 收藏当前”，保持“自动更新进度”开启。
3. 正常播放时自动保存集数和时间；以后点击收藏条目继续观看。
4. 如需跳过片头片尾，开启“启用自动跳过”，再开启对应的片头或片尾开关并设置秒数。

默认仅对已收藏的视频启用自动跳过。关闭自动跳过不影响进度保存；新收藏的 B站合集默认关闭片头、片尾跳过，需要自行确认时间后启用。

## 播放设置

| 设置 | 含义 |
| --- | --- |
| 片头秒数 | 从视频开头跳到该时间点 |
| 片头旁“取当前” | 把当前播放位置设为片头结束，并开启片头开关 |
| 片尾秒数 | 距视频结尾的剩余秒数，例如 90 表示最后 90 秒 |
| 片尾旁“取当前” | 将当前位置设为片尾开始，自动计算“总时长减当前位置”，并开启片尾开关 |
| 短视频保护 | 短于设定时长的视频不执行自动跳过 |
| 直接切下一集 | 满足条件时尝试网站的下一集操作 |
| 完播自动重置 | 启用后可回到开头；自动下一集优先于重播 |

快捷设置沿用当前设置范围，不会自动开启“启用自动跳过”总开关。合集可勾选“仅设置当前这一集”覆盖合集默认参数。

默认快捷键为 `Shift + →` 快进、`Shift + ←` 快退，步长和按键可调整。在输入框和可编辑文字区域中不拦截这些快捷键。

## 收藏、排序与选集

### 排序与置顶

- 工具栏选择“最近观看”或“名称排序”；最近顺序参考点击续看和进度保存时间。
- 鼠标移到收藏上，可使用置顶、选集、移动文件夹和删除操作。
- 置顶条目优先显示。弹窗打开期间，后台进度更新不会打乱最近观看列表；点击刷新图标或关闭重开后重新排序。

### B站合集

对已识别的 B站视频合集，收藏一次后，不同视频会更新同一收藏。合集身份依据合集编号，集数取标题中的“第 N 集／话”，不把“37/48”之类的列表位置当作真实集数。

打开合集视频并播放后，扩展会缓存页面可识别的集数。点击收藏上的“选集”展开目录：

- **未看**：没有已记录的播放进度。
- **看到一半**：存在播放进度，尚未达到完成阈值。
- **已看完**：播放位置达到总时长的 95%，或距结尾不足 30 秒。这是位置估算，不代表完整观看证明。

已有记录的集数直接打开保存地址续看；未看集数通过已保存的合集视频页面定位并选择。找不到唯一匹配时提示用户在网页中选集。自动下一集仅匹配当前合集中的下一话，不会主动选择推荐视频。

当前适配已验证结构的 B站 `video-pod` 合集。未使用明确集数命名、目录尚未加载或网站结构变化时，可能无法完整识别。非合集页面至少可展示已记录的集数。

### 进度与旧数据

每集播放位置分别保存。开启“仅记录最大集数”时，收藏主条目保留较高集数，同时仍记录回看集数的独立进度。接近播放结尾的记录再次打开时可能从头播放。

旧收藏和设置会保留。旧单视频收藏重新打开原视频并保存进度后，可关联到识别出的合集。旧版未保存的逐集历史无法补回；已有重复收藏不会自动删除，不同合集不会自动合并。

## 备份与恢复

弹窗和选项页使用同一种 JSON 备份格式，兼容旧版收藏备份。同名记录导入时保留更新时间较新的记录。

备份包含收藏、文件夹、逐集进度、已缓存选集目录、置顶状态，以及收藏和单集设置。**不包含全部全局设置、快捷键和自定义规则**；更换安装来源或浏览器后需另行核对。数据仅在本地保存，不提供跨设备自动同步。

## 高级设置与反馈

右键扩展图标进入“选项”，可管理收藏和文件夹、配置站点标签与番剧名称规则，以及调整全局行为。

遇到不记录、认错合集或不跳转时：

1. 确认扩展版本，重新加载扩展并刷新视频页面。
2. 确认已收藏视频且“自动更新进度”开启。
3. 点击弹窗底部“反馈诊断”，检查复制内容后粘贴到 [Issue](https://github.com/yunyouren/Video-skipping-and-anime-TV-series-tracking-assistant/issues)，附上复现步骤。

诊断信息只复制到剪贴板，不自动发送；复制失败会显示可手动复制的文本。保存状态反映本次后台运行中的记录。分享前请检查其中的番剧名称等信息。

## 权限与隐私

观看记录和设置保存在 `chrome.storage.local`，扩展不上传至开发者服务器，也不加载远程执行代码。详情见[隐私政策](PRIVACY.md)。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存收藏、播放进度和设置 |
| `tabs` | 读取相关标签页标题和网址，将播放器信息关联到观看页面 |
| `<all_urls>` | 在不同视频站点及嵌入式播放器中运行视频识别与控制脚本 |

扩展基于 HTML5 视频元素工作，不保证所有网站、广告或特殊播放器兼容，不绕过网站登录、付费或播放限制，也不提供新集更新提醒。

## 开发与验证

主要文件：

| 文件 | 职责 |
| --- | --- |
| `content.js` | 视频识别、跳过、续看、合集目录读取与选集 |
| `background.js` | 串行合并收藏写入和保存诊断状态 |
| `tracker-core.js` | 收藏身份、逐集数据、备份校验与共用设置规则 |
| `popup.html` / `popup.js` | 扩展弹窗 |
| `options.html` / `options.js` | 高级设置 |

运行回归测试：

```sh
node --test tests/regression.test.cjs tests/collection.test.cjs tests/experience.test.cjs
```

可选真实浏览器检查（使用临时浏览器配置和本地媒体）：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser-smoke.cjs
```
